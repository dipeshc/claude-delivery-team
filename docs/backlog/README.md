# Backlog

This file is documentation, not a work item.

This directory holds filed work items: one file per item, with its priority
(`P0`–`P3`) encoded in the filename. Two subdirectories carry a fixed meaning:

- `blocked/` — items waiting on an owner decision or on environment
  (devices, credentials, live services).
- `deferred/` — items deliberately out of scope, never drifted into.

For the full item shape and lifecycle rules, see the team charter's
["Backlog conventions"](../team-charter.md#backlog-conventions) section.
