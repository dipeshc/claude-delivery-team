# Backlog

This file is documentation, not a work item.

This directory holds filed work items: one file per item, with its priority
(`P0`–`P3`) encoded in the filename. It also carries the `blocked/` and
`deferred/` subdirectories.

For what those subdirectories mean, the shape every item must have, and how an
item is marked done, see the team charter's
["Backlog conventions"](../team-charter.md#backlog-conventions) section.
